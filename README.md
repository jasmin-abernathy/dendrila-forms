# Dendrila Forms 🌱

Moteur libre et léger de questionnaires et d'entretiens, conçu pour un hébergement PHP sobre.

**État : prototype v0.1.** Les modèles fournis sont des démonstrations fictives et ne doivent pas servir à collecter des données sensibles. Les invitations privées, statistiques publiques, autorisations administrateur et publications éditoriales viendront dans des versions ultérieures.

Le code source, les tests et la documentation de déploiement accompagnent le premier lot de développement.
